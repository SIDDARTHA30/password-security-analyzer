# Password Security Analyzer (Python)

## Project Overview
This project is a Python-based tool that analyzes the strength of a password and highlights common security weaknesses.  
It helps users understand why weak passwords are risky and how strong passwords improve security.

---

## Objective
The main objective of this project is to:
- Check password strength using basic security rules
- Identify weak or commonly used passwords
- Educate users about secure password practices

---

## How the Project Works
1. The user enters a password.
2. The program checks:
   - Password length
   - Uppercase letters
   - Lowercase letters
   - Numbers
   - Special characters
3. The password is compared with a list of commonly used passwords stored in a file.
4. A security report is displayed with detected issues and suggestions.

---

## Features
- Password length validation  
- Character type checking (uppercase, lowercase, numbers, symbols)  
- Detection of commonly used passwords  
- Clear security feedback and suggestions  
- Simple and beginner-friendly design  

---

## Project Files
- analyzer.py – Main Python program that analyzes the password  
- common_passwords.txt – List of commonly used and weak passwords  
- README.md – Project documentation

## Tools and Technologies Used

## How to Run the Project
1. Make sure Python is installed.
2. Open terminal or command prompt in the project folder.
3. Run the program.
4. Enter a password when prompted.
